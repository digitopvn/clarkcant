Implementation: https://github.com/digitopvn/clarkcant/pull/367, merged b589e906fe995f283417977966501417b90a5580. Official paired documentation: https://github.com/digitopvn/clarkcant-web/pull/60, merged 83a4ff37abc4ff010dd91854c17d7e7379bfc91a; https://github.com/digitopvn/clarkcant-web/actions/runs/36706936732 deployed successfully. Internal widget development, architecture and open-interface docs are paired EN/VI.

Acceptance mapping:
1. Built-in widgets retain production semantic tokens/compiler; theme/frame browser regressions prove they follow the host.
2. Declarative Mini Apps retain semantic specs and scoped variables; detached composition/browser regression proves no content or state replacement.
3. Checked appearance arrives in iframe init before mount; SDK/host tests and four real runtime-backed iframe journeys prove it.
4. Live theme/scheme/reduced-motion changes retain the same frame and draft/props/state revision at 1280/390 light/dark; assertions check the actual reduced micro token.
5. Detached windows receive the exact host revision through named bootstrap/live IPC, without theme queries or credentials. Browser wiring and real Electron smoke prove initial/live revision, dedup, bootstrap update, raw-theme refusal and unsubscribe.
6. Definitions default to adaptive; fixed mode is disclosed in gallery/detail/Lab and directory-backed marketplace results when the claim exists. SSR tests prove both modes; discovery metadata is never installed authority or permission.
7. Appearance produces no semantic-state POST or model turn; browser journeys assert zero churn while content, props/state, provenance and fallback remain unchanged.
8. SDK snapshots are checked, copied and deeply frozen; optional DOM helpers write only canonical bounded variables. Source/nonce and shell-only IPC reject detached/subframe senders and nested privileged/raw styling. No new widget capability, generic IPC or host access.

Local evidence: focused 124 tests, desktop boundary/security 48, 15 detached/theme/frame regressions; verify:full passed with 4,930 unit tests and 320 browser journeys. After a smoke-only test-data correction, pnpm verify passed with 4,931 unit tests. Existing 34 unit and 3 externally gated browser skips remain. Four meaningful mutations (initial delivery, live dispatch, freezing, fixed disclosure) failed and restored exact bytes. Conditional simplifier and root REVIEW.md review completed.

Compatibility: bridge v2 is intentional. Current SDK accepts v1 hosts without appearance; old strict bundled v1 SDKs must rebuild for a v2 host. Both official languages document this requirement.
