# Neo Brutalism

A data-only ClarkCant reference theme: nearly square corners, three-pixel structural lines, hard offset shadows, heavy headings and raised/pressed controls. Host recipes keep approval, Stop, focus and disabled semantics protected. No CSS or JavaScript is supplied.

From the ClarkCant checkout:

```sh
node packages/widget-cli/src/cli.ts theme dev examples/themes/neo-brutalism
node packages/widget-cli/src/cli.ts theme test examples/themes/neo-brutalism
node packages/widget-cli/src/cli.ts theme pack examples/themes/neo-brutalism
```

The preview uses production components locally. Static conformance retains unverified browser checks; check keyboard, narrow/normal widths and reduced motion in the dev host. Register/install this directory through the existing package lifecycle, then select **Neo Brutalism** under Settings → Experience. Theme reference: `package:org.clarkcant.neo-brutalism#neo-brutalism`. The Glass Orb default applies only without an explicit personal Orb preference. Reduced motion remains authoritative.

Font policy: host-owned `system` body/display profiles and the `clark` monospace profile. No font files are bundled and no external fonts are requested; platform fallback fonts may differ. Original theme data is Apache-2.0; see [LICENSE](LICENSE) and the source URL in [clarkcant.json](clarkcant.json).

## Tiếng Việt

Theme tham chiếu chỉ chứa dữ liệu: góc gần vuông, đường cấu trúc dày ba pixel, bóng lệch cứng, tiêu đề đậm và nút nổi/có trạng thái nhấn. Recipe của host giữ nguyên ngữ nghĩa được bảo vệ của phê duyệt, Dừng, tiêu điểm và vô hiệu. Gói không cung cấp CSS hay JavaScript.

Chạy các lệnh ở trên từ checkout ClarkCant. Bản xem trước dùng component sản phẩm tại máy. Kiểm tra tĩnh giữ các kiểm tra browser ở trạng thái chưa được xác minh; kiểm tra bàn phím, khung điện thoại/thường và giảm chuyển động trong dev host. Đăng ký/cài thư mục qua vòng đời package hiện có, rồi chọn **Neo Brutalism** trong Cài đặt → Trải nghiệm. Orb Glass mặc định chỉ áp dụng khi chưa có lựa chọn Orb riêng. Giảm chuyển động luôn có hiệu lực cao nhất.

Chính sách phông chữ: profile `system` cho nội dung/tiêu đề và profile monospace `clark` do host sở hữu. Không đóng gói tệp phông, không yêu cầu tải phông bên ngoài; phông fallback có thể khác nhau giữa nền tảng. Dữ liệu theme nguyên gốc dùng Apache-2.0; xem LICENSE và URL nguồn trong manifest.
